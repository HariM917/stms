Users API Integration

This page demonstrates how to integrate the STMS Users API into any website using vanilla JavaScript.

Basic Usage

// Create an instance of the API
const api = new STMSUsersAPI('http://localhost:8001');

// Get users
api.getUsers().then(result => {
  if (result.success) {
    console.log(`Found ${result.count} users:`, result.users);
  } else {
    console.error('Error:', result.error);
  }
});

Rendering Users

The library provides a convenient method to render users in an HTML element:

// Render users in a container
const container = document.getElementById('users-container');
api.renderUsers(container, {
  title: 'System Users',
  showRefreshButton: true,
  showSearch: true
});
