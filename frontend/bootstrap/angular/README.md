# Angular Components for STMS

These are example Angular components for integrating with the STMS API. 
They are not meant to be used directly but serve as reference implementations.

To use these components in a real Angular project:

1. Copy the files to your Angular project
2. Install the required dependencies
3. Import the components in your Angular module

## Development

These files may show TypeScript errors in VS Code if you don't have the Angular dependencies installed.
This is expected and doesn't affect the functionality of the STMS system.
